How an account is made

The mess office issues a code against the person's name, and the role is attached to that code. When the code is redeemed it is spent, so it makes exactly one account.

RoleWhat that person sees
StudentThe published menu and their own attendance
Kitchen StaffThe kitchen tablet and the capture screen
Mess ManagerThe console, planning, waste and accuracy
Mess AdministratorThe masters: menus, recipes, ingredients, halls
Finance OfficerWaste cost and procurement, read only
AdministratorEverything, including the forecast settings
