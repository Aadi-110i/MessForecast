How offline capture works

Every scan is written to this tablet first, with its own identifier. If the network is down the scan waits in the queue and is sent the moment the connection returns.

Sending the same scan twice is harmless: the server ignores any identifier it has already stored, so a re-send never doubles a student’s attendance.
